# Week 7 — Concurrent Programming

**Module:** COM00142M Advanced Programming  
**University of York**

---

## Overview

Week 7 is the final week of the module and focuses on **concurrent programming** — one of the most complex and actively developing areas in software engineering. The week builds theory first (shared variables → message passing → known failure modes) and then moves to practical Python implementation.

Key framing: concurrent programming is primarily about **synchronisation and communication problems**, not just decomposition into parallel parts. A concurrent program is an abstract model of potential parallelism — it may or may not run in parallel depending on the infrastructure.

---

## Learning Outcomes

By the end of this week:
1. Articulate the fundamental problems underpinning concurrent design
2. Demonstrate solutions generated by the shared variable approach
3. Demonstrate solutions generated by the message passing approach
4. Implement simple concurrent programs in Python
