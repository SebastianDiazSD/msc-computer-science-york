# Week 4 – Advanced Programming: NumPy, Pandas & Data Preparation

## Overview
This week introduces two key Python libraries for data analysis — **NumPy** and **Pandas** — and covers the fundamentals of **data cleaning and preparation**. The focus is on understanding when to use each library, how to manipulate data efficiently, and how to prepare raw datasets for analysis.

## Learning Outcomes
By the end of this week you should be able to:
1. Identify mathematical terms and techniques associated with data preparation and analysis.
2. Articulate the advantages and disadvantages of NumPy and Pandas constructs within specific contexts.
3. Select and apply appropriate NumPy and Pandas data structures and functions to solve data cleaning and organisation problems.
