# Week 6 – Advanced Programming: Data Wrangling, Visualisation & Analysis

## Overview
Week 6 builds directly on Week 4 (NumPy, Pandas, data cleaning) and extends into more advanced data manipulation, visualisation, and analysis techniques. The four lessons cover reshaping and merging datasets, creating plots with Matplotlib and Seaborn, the full data analysis pipeline with `groupby`, and the special handling required for time-series and categorical data.

## Core Textbook
McKinney, W. (2017). *Python for Data Analysis*. 2nd ed. O'Reilly Media.

| Lesson | Sections |
|---|---|
| Lesson 1 – Data Wrangling | Sections 8.1, 8.2, 8.3 |
| Lesson 2 – Data Visualisation | Chapter 9 |
| Lesson 3 – Data Analysis | Chapter 10 |
| Lesson 4 – Special Data Types | Chapter 11 |

## Learning Outcomes
By the end of this week you should be able to:
1. Apply data wrangling techniques for the grouping and reshaping of simple data sets.
2. Select and present the results of data analysis through appropriate visualisations.
3. Demonstrate the considerations required when handling time-series data.
4. Identify different data types and the considerations needed when cleaning, manipulating and analysing data.
