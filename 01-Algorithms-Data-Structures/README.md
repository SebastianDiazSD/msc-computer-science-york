# Algorithms and Data Structures

Implementation of core computer science algorithms and data structures in Python,
completed as part of the MSc Computer Science programme at the University of York.

---

## Topics Covered

| Week | Focus Area |
|------|-----------|
| 1 | Algorithm design and computational problem solving |
| 2 | Data structures, search algorithms, and control-flow patterns |
| 3 | Asymptotic analysis and Big-O complexity |
| 4 | Linear abstract data structures: stacks, queues, linked lists |
| 5 | Recursion, trees, and tree-based search algorithms |
| 6 | Sorting algorithms and divide-and-conquer strategies |
| 7 | Graph structures, traversal algorithms (BFS, DFS) |

---

- **Language**: Python 3
